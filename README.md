# Mohammed Amas — GitHub Pages Portfolio

A responsive bilingual English/Arabic developer portfolio styled after the supplied reference: dark UI, neon-blue accents, rabbit hero image, glowing cards, theme toggle, mobile navigation and project sections.

## Publish with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a new repository, for example `mohammed-amas-portfolio`.
3. Upload **all files in this folder** to the repository root. Keep `index.html` at the root.
4. In GitHub open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will show your live Pages URL. It will normally look like:
   `https://YOUR-USERNAME.github.io/mohammed-amas-portfolio/`
7. Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `robots.txt` and `sitemap.xml` with the real URL, then commit those two files again.

## CV

The Download CV button expects a file named `resume.pdf` in this folder. Add your CV with exactly that filename. If you don't have one yet, the button can be removed or changed.

## Notes

- No Firebase is required.
- This is a static site: HTML/CSS/JavaScript only.
- The site works on GitHub Pages because all local asset paths are relative.
- Google indexing is separate from publishing. After the site is live, submit its sitemap in Google Search Console if you want to request indexing.
